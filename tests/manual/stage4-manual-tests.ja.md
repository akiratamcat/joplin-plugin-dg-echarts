# 段階4 の手動テスト

設計書 18章の段階4（UI の仕上げ）のうち、Joplin の中でしか確かめられないことの手順。自動テスト（`npm test`）は通っている。

| 項目     | 内容                                                                                |
| -------- | ----------------------------------------------------------------------------------- |
| 対象     | `publish/io.github.akiratamcat.dg-echarts.jpl`（版数 0.4.0）。`npm run dist` で作る |
| 環境     | Joplin の最新の安定版（Windows）。表示言語は日本語                                  |
| ノート   | [mvp-note.md](mvp-note.md)（段階1 と同じ）                                          |
| 所要時間 | 約 30分                                                                             |

結果は、各「確認」の下に ○ / × とひとことを書く。PC のパス（`C:\...`）は書かずに、`spike/test/...` のように書く。

---

## A. 更新と設定画面

1. 「ファイルからインストール」で `publish/io.github.akiratamcat.dg-echarts.jpl`（0.4.0）を選び、再起動する（0.3.0 に上書きする）。
2. **確認 A-1**：プラグインの一覧で、版数が 0.4.0 になっている。dg-echarts が2つ並んでいない。
3. **確認 A-2**：設定の dg-echarts の画面に「グラフのツールバーを表示する」「Markdown エディタで ECharts のブロックを色分けする」「同梱している外部のソフトウェア」が加わっている。
4. **確認 A-3**：「同梱している外部のソフトウェア」の一覧を開くと、7 行（Apache ECharts 6.1.0、Parts of d3、ZRender 6.1.0、tslib 2.3.0、DOMPurify 3.4.17、regenerator-runtime、YAML 2.9.1）が、それぞれライセンスと公式サイトつきで並ぶ。項目を選んでも何も起きない。

**確認 A-1**：期待通り。
**確認 A-2**：期待通り。
**確認 A-3**：期待通り。

## B. 図のツールバー（設計書 11章）

1. mvp-note のノートを開く。
2. **確認 B-1**：図にマウスを乗せると、図の右上に5つのボタンが出る。マウスを外すと消える。エラーの枠（15〜20番）にはボタンが出ない。
3. **確認 B-2**：ボタンにマウスを乗せると、名前（「SVG をコピー」「PNG をコピー」「SVG を保存」「PNG を保存」「グラフのソースをコピー」）が出る。
4. 1番の「SVG をコピー」を押す。**確認 B-3**：「SVG をコピーしました。」と出る。テキストエディタに貼ると `<svg height="400" width="800" ...` で始まる SVG の文字になる。
5. 1番の「PNG をコピー」を押す。**確認 B-4**：「画像（PNG）をコピーしました。」と出る。ペイントなどに貼ると、図の画像（1600×800 ピクセル、白い背景）になる。
6. 1番の「SVG を保存」を押し、フォルダーを選ぶ。**確認 B-5**：「保存しました: ...」と出て、`ノートの題名-1.svg` ができる。ブラウザで開くと図が出る。同じ操作をもう一度すると `-1-2.svg` になり、上書きされない。
7. 6番（theme=dark）の「PNG を保存」を押す。**確認 B-6**：`ノートの題名-6.png` ができ、暗い背景の図になる。
8. 2番（YAML）の「グラフのソースをコピー」を押す。**確認 B-7**：「グラフのソースをコピーしました。」と出て、貼ると YAML のソース（コメントを含む）になる。
9. **確認 B-8**：キーボードの Tab キーでボタンに移ると、ボタンが見えて、Enter キーで押せる。
10. 設定で「グラフのツールバーを表示する」を無効にする。**確認 B-9**：図にマウスを乗せてもボタンが出ない。有効に戻す。

**確認 B-1**：期待通り。
**確認 B-2**：期待通り。
**確認 B-3**：期待通り。
**確認 B-4**：期待通り。
**確認 B-5**：期待通り。
**確認 B-6**：期待通り。
**確認 B-7**：期待通り。
**確認 B-8**：tab キーを押すと、ノートへの入力となり、確認が出来なかった。（作者の判断で、重要度が低いので確かめないことにした。）
**確認 B-9**：期待通り。

## C. Markdown エディタの色分け（設計書 7.7節）

1. mvp-note のノートを Markdown エディタで開く（分割表示でもよい）。
2. **確認 C-1**：` ```echarts ` のブロックの中で、キー（`"title"`、`xAxis:` など）、文字列、数値、`true` / `false` / `null`、YAML のコメント（`# Sales per month`）に色が付く。21番の普通の JSON のブロックには色が付かない（Joplin の標準の色分けのまま）。
3. **確認 C-2**：Joplin のテーマを暗いものにしても、色が読める。明るいテーマに戻す。
4. 設定で「Markdown エディタで ECharts のブロックを色分けする」を無効にし、ノートを開き直す。**確認 C-3**：色が付かなくなる（Joplin を再起動しないと変わらない場合は、そう書く）。有効に戻す。

**確認 C-1**：期待通り。
**確認 C-2**：期待通り。
**確認 C-3**：期待通り。再起動は不要。

## D. エクスポートとリッチテキストエディタ

1. PDF にエクスポートする。**確認 D-1**：PDF にツールバーのボタンが写っていない。
2. HTML ファイルにエクスポートし、ブラウザで開く。**確認 D-2**：図にマウスを乗せてもボタンが出ない（メインスクリプトのない HTML ではツールバーを付けない）。
3. リッチテキストエディタに切り替える。**確認 D-3**：図が出て、ノートが壊れない（ボタンは出ても出なくてもよい）。Markdown エディタに戻して、ソースが変わっていない。

**確認 D-1**：期待通り。
**確認 D-2**：期待通り。
**確認 D-3**：期待通り。
