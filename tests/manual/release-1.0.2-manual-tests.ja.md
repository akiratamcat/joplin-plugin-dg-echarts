# 1.0.2 の手動テスト

1.0.2 の修正（文字の書体・太さ・斜体の値から `style` 属性に入る CSS。`CHANGELOG.ja.md`）のうち、Joplin の中でしか確かめられないことの手順。自動テスト（`npm test`）は通っている。描画テストでは、同じノートを表示して外部への要求が出ないことと、4つの図が描かれることを確かめている。

| 項目     | 内容                                                                                           |
| -------- | ---------------------------------------------------------------------------------------------- |
| 対象     | `publish/io.github.akiratamcat.dg-echarts.jpl`（版数 1.0.2）。`npm run dist` で作る            |
| 環境     | Joplin の最新の安定版（Windows）。表示言語は日本語                                             |
| ノート   | [release-1.0.2-note.md](release-1.0.2-note.md)、[release-1.0.1-note.md](release-1.0.1-note.md) |
| 所要時間 | 約 15分                                                                                        |

結果は、各「確認」の下に ○ / × とひとことを書く。PC のパス（`C:\...`）は書かずに、`spike/test/...` のように書く。

---

## A. 更新

1. 「ファイルからインストール」で `publish/io.github.akiratamcat.dg-echarts.jpl`（1.0.2）を選び、再起動する（1.0.1 に上書きする）。
2. **確認 A-1**：プラグインの一覧で、版数が 1.0.2 になっている。dg-echarts が2つ並んでいない。

**確認 A-1**：期待通り。

## B. 外部への要求が出ない（設計書 12章）

1. 新しいノートを作り、`release-1.0.2-note.md` の中身を貼る。
2. 「ヘルプ → 開発ツールの切り替え」で開発ツールを開き、Network のタブを選ぶ。フィルタに `example.com` と入れる。
3. ノートを開き直す（ほかのノートに移ってから戻る）。
4. **確認 B-1**：1〜4番の図が表示される。1番の題名と、2番・3番の棒の上の数字が見える。
5. 1〜3番の図の上で、マウスをゆっくり動かす。
6. **確認 B-2**：Network のタブに `example.com` への要求が1つも出ない（ノートを開いたときも、マウスを動かしたときも）。

**確認 B-1**：期待通り。
**確認 B-2**：期待通り。Network タブに検出されたファイルは、全て file:///c:/ のようにローカルディスクを参照していた。

## C. ふつうの書体はこれまでどおり

1. 4番の図を見る。
2. **確認 C-1**：題名が太字の明朝体（Times New Roman）で、棒の上の数字が斜体になっている。
3. 1.0.1 の手動テストのノート（`release-1.0.1-note.md`）と、1.0.0 で作った図のノート（`mvp-note.md` など）を開く。
4. **確認 C-2**：1.0.1 のときと同じに表示される（`release-1.0.1-note.md` の 4番の強調表示とグラデーション、5番の「4 行目」のエラーを含む）。`example.com` への要求も出ない。

**確認 C-1**：グラフのタイトルも、グラフ中の棒グラフ内に配置された数値も期待通りの表示。
**確認 C-2**：期待通り。

2. **確認 D-1**：1〜4番の図が出る。4番の題名は太字の明朝体になっている。
