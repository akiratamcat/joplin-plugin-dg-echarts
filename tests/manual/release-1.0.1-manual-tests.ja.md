# 1.0.1 の手動テスト

1.0.1 の修正（色の値の CSS の `url()`、強調表示の `<style>`、JSON の行番号。`CHANGELOG.ja.md`）のうち、Joplin の中でしか確かめられないことの手順。自動テスト（`npm test`）は通っている。描画テストでは、同じノートを表示して外部への要求が出ないことと、5番の行番号を確かめている。

| 項目     | 内容                                                                                |
| -------- | ----------------------------------------------------------------------------------- |
| 対象     | `publish/io.github.akiratamcat.dg-echarts.jpl`（版数 1.0.1）。`npm run dist` で作る |
| 環境     | Joplin の最新の安定版（Windows）。表示言語は日本語                                  |
| ノート   | [release-1.0.1-note.md](release-1.0.1-note.md)                                      |
| 所要時間 | 約 15分                                                                             |

結果は、各「確認」の下に ○ / × とひとことを書く。PC のパス（`C:\...`）は書かずに、`spike/test/...` のように書く。

---

## A. 更新

1. 「ファイルからインストール」で `publish/io.github.akiratamcat.dg-echarts.jpl`（1.0.1）を選び、再起動する（1.0.0 に上書きする）。
2. **確認 A-1**：プラグインの一覧で、版数が 1.0.1 になっている。dg-echarts が2つ並んでいない。

**確認 A-1**：期待通り。

## B. 外部への要求が出ない（設計書 12章）

1. 新しいノートを作り、`release-1.0.1-note.md` の中身を貼る。
2. 「ヘルプ → 開発ツールの切り替え」で開発ツールを開き、Network のタブを選ぶ。フィルタに `example.com` と入れる。
3. ノートを開き直す（ほかのノートに移ってから戻る）。
4. **確認 B-1**：1〜3番の図が表示される。1番の棒と背景は塗られず（棒は見えない）、題名の文字も見えない。
5. 2番と3番の棒に、ゆっくりマウスを乗せる。
6. **確認 B-2**：Network のタブに `example.com` への要求が1つも出ない（ノートを開いたときも、マウスを乗せたときも）。
7. **確認 B-3**：2番と3番の棒は、マウスを乗せても色が変わらない（強調表示のスタイルを空にしたため）。

**確認 B-1**：期待通り。
**確認 B-2**：期待通り。
**確認 B-3**：期待通り。

## C. ふつうの図はこれまでどおり

1. 4番の棒にマウスを乗せる。
2. **確認 C-1**：棒は、青から緑のグラデーションで塗られている。マウスを乗せた棒は赤く変わり、外すと戻る。
3. 1.0.0 で作った図のノート（`mvp-note.md` など）を開く。
4. **確認 C-2**：これまでと同じに表示される。棒にマウスを乗せたときの強調表示も、これまでどおり出る。

**確認 C-1**：期待通り。
**確認 C-2**：期待通り。

## D. JSON の行番号

2. **確認 D-1**：エラーの枠に「4 行目」と、該当行（`"series": [{ "type": "bar", "data": [1, 2,] }]`）の抜粋が出る。

**確認 D-1**：期待通り。
